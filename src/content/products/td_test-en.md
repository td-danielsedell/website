You get a quick answer to the question that matters most: **does Maximo still work the way the business expects?** If something goes wrong, TD Test shows where in the flow the error occurred, what happened and what the screen looked like. The tests leave the database unchanged, so they can be repeated without affecting your data.

TD Test supports both IBM Maximo 7.x and IBM Maximo Application Suite (MAS), and the same tests can be run against either version. That makes it easy to verify that processes and customisations still work after an upgrade.

Unlike traditional testing tools, TD Test works directly against Maximo without going through the browser. That gives faster, more stable tests that do not need rewriting when the interface changes.
