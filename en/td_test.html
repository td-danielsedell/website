TD Test

Quality-assure your IBM Maximo

TD Test automates testing of IBM Maximo and replaces time-consuming manual checks. A workflow is defined once and can then be tested over and over again – after upgrades, after customisations, or ahead of deployment.

You get a quick answer to the question that matters most: does Maximo still work the way the business expects? If something goes wrong, TD Test shows where in the flow the error occurred, what happened and what the screen looked like. The tests leave the database unchanged, so they can be repeated without affecting your data.

TD Test supports both IBM Maximo 7.x and IBM Maximo Application Suite (MAS), and the same tests can be run against either version. That makes it easy to verify that processes and customisations still work after an upgrade.

Unlike traditional testing tools, TD Test works directly against Maximo without going through the browser. That gives faster, more stable tests that do not need rewriting when the interface changes.

CAPABILITIES

What can TD Test do?

"Testing Maximo with the help of Maximo."
TD Test works from inside Maximo, and so reaches the interface, the business logic and more.

Test what matters

TD Test can automate tests of:

  • Maximo's user interface and business logic
  • Integrations with other systems
  • Your own customisations and functions
  • Complete business processes
  • Flows with several users, for example approval and handover

See straight away what went wrong

After every run TD Test gives you:

  • A result for each test step
  • Error messages and relevant log extracts
  • Screenshots from every step
  • History of earlier test runs
  • Automatic reporting to Teams, for example

Run it on your terms

TD Test gives you the flexibility to:

  • Run single tests or whole test groups
  • Schedule recurring runs
  • Start tests directly from the browser
  • Integrate with Jenkins, for example
  • Control the log level per test without affecting Maximo's normal settings

BENEFITS

Why TD Test?

Fast

TD Test works directly against Maximo, without the detour through a browser. That gives tests that can run up to 100 times faster.

Stable

TD Test is not affected by changes to Maximo's interface or by browser behaviour. The tests are more stable and need less maintenance as Maximo changes.

Cost-effective

TD Test needs no dedicated hardware and can run as a container in an environment you already have. Fast implementation and less test maintenance deliver benefit quickly.

Easy to use

TD Test follows the same logic and the same names as Maximo, which makes the tests easy to create and to follow. Clear reporting shows exactly where the error occurs.
